# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Design intelligence: UI/UX Pro Max (`search.py --domain chart` for "line chart trend accessible table alternative" and "comparison bar"; `--domain ux` for "financial calculator form number input", "comparison table mobile stacked", "tooltip hover touch", "data table sort empty loading skeleton"; `--domain product` for "real estate investment analysis dashboard fintech calculator"; `--stack svelte`; run 2026-10-04). **Adopted:** a line chart for trend-over-time, with series told apart by **line style and marker shape, not color alone**, plus a data-table alternative with timestamps (chart A11y Fallback); visible legends next to the chart; a text summary for screen readers; a meaningful empty state instead of a blank axis; a placeholder of the same size while a chart loads (no empty axis frame); an error state with a retry action; locale-aware number formatting with thousands separators; tabular figures for every money and percent column; `inputmode` on numeric fields; a visible label on every input; a card layout instead of a wide table on mobile; tap rather than hover for anything important (so metric definitions are **visible text, not tooltips**); and loading-then-result feedback on every action. **Rejected:** the product search's "Trust Blue + Gold, Glassmorphism" palette and style, and "Dark Mode (OLED)" (these conflict with the locked Phase 2 warm editorial tokens); chart "Fill: 20% opacity" area fills (they create unlisted color values); hover + zoom chart interaction (nothing in a chart may be hover-only, and the table carries every value); radar charts for deal comparison (the compare view is a table by design); and "bulk actions" (compare selection is capped at 3). **No new hex values.**

**Sources legend:** `[CTX]` 07-CONTEXT.md (locked), `[P2]` approved 02-UI-SPEC.md, `[P3]` approved 03-UI-SPEC.md, `[P4]` approved 04-UI-SPEC.md, `[P5]` approved 05-UI-SPEC.md, `[REQ]` REQUIREMENTS.md / ROADMAP.md (INV-01..06), `[STACK]` CLAUDE.md, `[SKILL]` UI/UX Pro Max, `[D]` researcher discretion (CONTEXT "Claude's Discretion", or a UI detail upstream documents don't cover).

**Honesty rules for this phase (apply to every string below):**
1. The analyzer does arithmetic on the user's inputs. Copy never recommends buying, never ranks a deal as "good", "bad", or "best", and never predicts returns. Comparison markers say **Highest** or **Lowest**, never "best" or "winner".
2. Every RentCast figure is an **estimate**, shown with its range and its comparable count ("based on 8 comparables"). Market medians show the number of listings behind them. The word "value" appears only in the compound "value estimate". "Appraisal", "appraise", "guarantee", "CMA", and "worth" (for a property) never appear.
3. "Not investment, legal, or tax advice" appears on the analyzer, the memo page, and every printout.
4. No status is shown by color alone. Comparison markers, chart series, expense-unit toggles, and the 1% rule result each carry an icon, a shape, or words.
5. Negative money is never shown in red. A negative cash flow is a fact, not an error. It uses a true minus sign (U+2212) in the normal text color.

### LayerChart token reconciliation `[D]`

LayerChart's default classes come from `@layerstack/tailwind` (for example `fill-surface-content`, `stroke-surface-content/50`). Under Phase 2's `--color-*: initial` guardrail, those classes resolve to nothing. Contract:
1. Every LayerChart primitive used (`Chart`, `Svg`, `Axis`, `Grid`, `Spline`, `Points`, `Text`) receives explicit token classes through its `class`/`classes` props (for example `stroke-primary`, `fill-muted-foreground`). No LayerChart default color class is relied on.
2. A component test renders each chart with a fixture and asserts that every `<path>`, `<line>`, `<text>` and marker in the SVG has a computed `stroke` or `fill` equal to one of the six chart tokens below (or `none`).
3. LayerChart is dynamically imported inside market routes and the print route only. Marketing routes never load it `[P2 CSP & performance]`.
4. LayerChart may write inline `style` attributes on SVG nodes. Phase 1 already permits `style-src-attr` (proven by the CSP E2E), so the CSP stays unchanged. If the planner finds LayerChart injects a `<style>` element, that is a blocker to raise, not something to work around with `unsafe-inline`.

### Native `<select>` styling `[D]`

Used for **Property type** (analyzer, buy box) and **Sort by** (deals list). Same metrics as Phase 3 `input`: 48px tall, `card` fill, 1px `input` border, `--radius-md`, padding-inline 16px with 48px on the right for a Lucide `ChevronDown` 16px icon (`aria-hidden`, `pointer-events: none`) painted by a wrapper, Body 16/400, `appearance: none`. Focus, invalid, and disabled states follow Phase 3. A native select keeps the OS picker on mobile and needs no new primitive.

## Typography

Reused: exactly **4 sizes** (14 / 16 / 24 / 40) and **2 weights** (400, 600) `[P2]`. Phase 7 introduces no size and no weight. It adds one **role**, Figure, which reuses existing sizes in the Inter family.

| Role | Family | Size | Weight | Line Height | Phase 7 usage |
|------|--------|------|--------|-------------|---------------|
| Label | Inter | 14px | 600 (chips, marker badges "Highest"/"Lowest", sub-nav current item is NOT this, legend labels) / 400 (metric definitions, helper text, as-of lines, chart axis ticks, table captions, "based on N comparables" lines, print provenance) | 1.4 | Small meta |
| Body | Inter | 16px | 400 (paragraphs, input text, table cells, memo text) / 600 (field labels, metric labels, fieldset legends, table headers, button labels, card titles as `h3`, sub-nav links when current) | 1.6 | Everything else |
| Figure | Inter, `font-variant-numeric: tabular-nums` | 24px (metric values, stat values) and **40px only for the Monthly cash flow headline** in the results panel | 600 | 1.2 | Every computed metric value |
| Heading | Fraunces | 24px | 600 | 1.25 | Section `h2`s, results panel title, chart titles, print report title, dialog titles |
| Display | Fraunces | 40px | 600 | 1.1 | The single `h1` on each investor route (screen only) |

Rules:
- **All financial numbers use Inter with `tabular-nums`**: inputs, metric values, table cells, chart tick labels, chips, comparison cells, and print tables `[SKILL number-tabular]`. Fraunces never renders a figure.
- Numbers in tables and the compare view are right-aligned. Numbers in inputs are left-aligned (editing position stays predictable).
- Formatting (`packages/core` formatters, unit-tested):
  - Money: `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD', maximumFractionDigits: 0 })` → "$1,850", "$312,000". Monthly and annual figures are whole dollars.
  - Negative money: U+2212 minus before the dollar sign → "−$142". Never parentheses, never red.
  - Percent: 1 decimal → "6.4%" (cap rate, cash-on-cash, rent-to-price at 2 decimals: "0.82%", because the 1% rule needs the hundredths).
  - DSCR: 2 decimals → "1.18". GRM: 1 decimal → "10.4".
  - Ranges: "$1,700 to $2,000" (the word "to", not an en dash, so screen readers read it plainly).
  - Missing value: an em dash "—" with a visually hidden "Not available" and the reason text visible beside it.
- Inputs format on blur (thousands separators added) and accept "250000", "250,000", or "$250,000" when typed.
- The print report title uses the **Heading** role (24px), not Display: a 40px title wastes the first printed page. Semantic level stays `h1`.
- No text below 14px. No Fraunces below 24px `[P3]`.

## Shape, Elevation, Motion

Phase 2 tokens `[P2]`: `--radius-md` 8px (inputs, selects, buttons, unit toggle outer corners, chart placeholder), `--radius-lg` 16px (fieldset cards, results panel, deal cards, compare table wrapper, chart figures, print sheet on screen), `--radius-full` (chips, marker badges). `--shadow-card` on the results panel, deal cards, chart figures and the print sheet on screen; `--shadow-card-hover` on dialogs. `--ease-out`, `--duration-fast` 150ms, `--duration-base` 200ms.
