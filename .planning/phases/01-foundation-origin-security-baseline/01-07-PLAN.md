<decisions_reference>
- D2/D3 (CONTEXT Research Amendments): the app is hidden via `<html hidden>` + external `frame-guard.js`; Svelte 5 transitions need `style-src-attr 'unsafe-inline'`. Both are verified here at runtime.
- RESEARCH Pitfall 2: a framing test that only calls `toBeHidden()` passes vacuously when the frame never loaded. Assert `html[hidden]` is PRESENT (proving the document loaded) AND that the `h1` is not visible.
- RESEARCH Pattern 2 evidence: Chromium blocks the `top.location` bust without a user gesture; the content simply stays hidden. Do not assert that the top page navigated.
- RESEARCH Pitfall 3: in dev, Kit adds `'unsafe-inline'` to `style-src`, so only BUILT output is authoritative. These specs run against the emulator serving `apps/web/build*`.
- Do NOT add a `<noscript>` reveal: sandboxed frames without `allow-scripts` render `<noscript>`, which would re-open clickjacking.
</decisions_reference>
