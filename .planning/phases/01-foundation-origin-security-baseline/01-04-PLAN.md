<objective>
Write the independent CSP contract oracle (`scripts/assert-csp.mjs`) that inspects the built HTML of both base-path builds, and mutation-test it so the oracle itself is trustworthy.

Purpose: FND-02 says every deployed page carries a strict CSP whose `connect-src` allows only the approved hosts. `kit.csp` generates the policy; this script is the second, independent check that fails the build when the policy regresses. It also enforces the FND-03 carriers (`<html hidden>`, `frame-guard.js`) and the FND-01 carriers (`.nojekyll`, `404.html`, the full page set).
Output: `pnpm csp:assert` green over both builds, plus a scripts-project test suite that proves the script catches five injected faults.
</objective>

`checkHtml(relPath, html)` returns an array of error strings, each prefixed with `relPath`, covering:
1. `<html>` must carry the `hidden` attribute (anti-framing, FND-03)
2. the CSP meta must exist in `<head>`; if absent, record `CSP meta missing` and stop checking that page
3. only `<meta charset...>` may precede the CSP meta (D1); anything else is an error naming what was found
4. for every key in `EXACT`, the page's directive token set must match exactly (order-insensitive, via a `sameSet` helper)
5. `frame-ancestors`, `report-uri`, `sandbox` must NOT appear (meta CSP silently ignores them, which is a false sense of safety)
6. `script-src` tokens may only be `'self'` or `'sha256-…'`
7. `style-src` tokens may only be `'self'`
8. `style-src-attr`, if present, must be exactly `['unsafe-inline']`
9. every inline `<script>` (one with no `src=`) must have its sha256 hash present in `script-src`

HTML-entity decoding (`&quot; &#39; &lt; &gt; &amp;`) before parsing the policy, comment stripping inside `<head>`, and the `walk()` directory recursion are all in the RESEARCH version — keep them.

`checkBuild(dir)` returns an array containing: a `missing <file>` error for each of `.nojekyll`, `frame-guard.js` and every `EXPECTED_PAGES` entry that is absent, then the concatenated `checkHtml` results for every `.html` file found by `walk(dir)`.

CLI tail (so the file is both importable and runnable):
```js
import { pathToFileURL } from 'node:url';

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
	const dir = process.argv[2] ?? 'build';
	const errors = checkBuild(dir);
	if (errors.length) {
		console.error(`CSP assertion failed (${errors.length}):\n- ` + errors.join('\n- '));
		process.exit(1);
	}
	console.log(`CSP assertion passed for ${dir}`);
}
```

Keep the whole file dependency-free (only `node:fs`, `node:path`, `node:crypto`, `node:url`) and under ~120 lines.
