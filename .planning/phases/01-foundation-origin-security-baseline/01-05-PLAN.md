  <action>
Reproduce the verified emulator from RESEARCH "Code Examples → `scripts/serve-pages.mjs`" exactly, dependency-free (`node:http`, `node:fs`, `node:path` only).

Behaviour that must hold (this is the whole point of the script):
- a request for a directory WITHOUT a trailing slash responds `301` with a `location` of the same path plus `/` (and preserved query string)
- a directory WITH a trailing slash serves its `index.html` at status `200`, or the site `404.html` at status `404` if there is no index
- an unknown path serves the site `404.html` with status `404` (never 200)
- a path outside the mount prefix, or one that escapes the served directory after `path.join`, serves the 404 page (path-traversal guard)
- content types are mapped for `.html`, `.js`, `.css`, `.json`, `.svg`, `.woff2`
- the root listener starts only if `apps/web/build` exists; the sub listener only if `apps/web/build-sub` exists
- the attacker listener always starts (even when neither build directory exists), answers `GET /` with status 200, and serves a document containing exactly these three iframes (ids are a contract for plan 07; the 200 at `/` is a contract for Task 2's `webServer.url` readiness probe):
  - `id="plain"` → `http://127.0.0.1:<ROOT>/`
  - `id="sandboxed"` `sandbox="allow-forms"` → `http://127.0.0.1:<ROOT>/renter/`
  - `id="sandboxed-scripts"` `sandbox="allow-scripts allow-same-origin"` → `http://127.0.0.1:<ROOT>/agent/`
- all three ports come from `E2E_PORT_ROOT` / `E2E_PORT_SUB` / `E2E_PORT_ATTACKER` with defaults 4273/4274/4275, and every listener binds `127.0.0.1` only

Smoke it manually before finishing: start `node scripts/serve-pages.mjs` in the background, then check with curl that `/renter` returns 301, `/renter/` returns 200, `/nope/` returns 404, and `http://127.0.0.1:4274/tran_real_estate/renter/` returns 200. Stop the process you started.
  </action>
