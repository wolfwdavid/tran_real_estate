  <behavior>
    History:
    - historyEvents(null | {}) -> []
    - one entry {'2026-09-28': {price: 2150, listedDate: '2026-09-28'}} -> [{ date: '2026-09-28', kind: 'listed', rent: 2150, change: null }]
    - entries sorted by date key ascending internally, returned NEWEST FIRST; a later entry with a different price and no removedDate -> 'rent-changed' with change = new - previous (negative allowed); same price -> not emitted as rent-changed (skipped)
    - an entry with a non-null removedDate -> 'delisted' dated removedDate (rent = that entry's price, change null); the next entry after a delisting -> 'relisted'
    - historySummary(events) -> { kind: 'none', listedOn } when only 'listed'; { kind: 'one', from, to, on } for exactly one rent change; { kind: 'many', first, firstOn, last, lastOn } for 2+; null for []
    - pricePoints(events) -> rents oldest-first, excluding delisted entries
    Sparkline:
    - sparklinePath([], 320, 48) -> null; ([5], …) -> null
    - sparklinePath([1,2,3], 320, 48, 2) starts with 'M2.0,46.0' and ends with 'L318.0,2.0'
    - equal values -> a flat line at h - pad (no division by zero)
    - lastPoint([1,2,3], 320, 48, 2) -> { x: 318, y: 2 }
    Contact links:
    - telHref('4055550142') -> 'tel:+14055550142'; ('1-405-555-0142') -> 'tel:+14055550142'; ('555') -> null; (null) -> null
    - formatPhone('4055550142') -> '(405) 555-0142'; invalid -> null
    - mailtoHref('jane.doe@example.com') -> 'mailto:jane.doe@example.com'; ('bad@') -> null; ('a b@example.com') -> null; ('x@example.com?body=hi') -> null
    - safeHttpUrl('javascript:alert(1)') -> null; ('data:text/html,x') -> null; ('example.com/agents/x') -> 'https://example.com/agents/x'; ('http://example.com') -> 'http://example.com/'; ('') -> null
    - outboundSearchLinks('418 Larkspur Ln, Harlow Springs, OK 74201') -> exactly 3 entries in order google, zillow, apartments with the UI-SPEC URL shapes and encodeURIComponent'd address
    - looksLikeListingId('3821-Hargis-St,-Austin,-TX-78723') -> true; ('') -> false; ('<script>') -> false; a 300-char string -> false
    Listing status (now = 2026-10-15T12:00Z):
    - Active, lastSeen 2026-10-10 -> { kind: 'recent', lastSeen: '2026-10-10' }
    - Active, lastSeen 2026-10-07 (8 days) -> { kind: 'stale', lastSeen }
    - Active, lastSeen exactly 7 days -> 'recent'
    - status 'Inactive' or removedDate set -> { kind: 'gone' }
    - Active, lastSeen null -> 'stale' with lastSeen null
    Format:
    - formatRent(2150) -> '$2,150'; (2150.6) -> '$2,151'; (null) -> null
    - formatMonthDay('2026-10-02') -> 'Oct 2' (UTC); formatMonthDayYear('2026-09-28') -> 'Sep 28, 2026'; formatMonthYear('2026-10-01') -> 'Oct 2026'
    - relativeListed('2026-10-15', now) -> 'today'; '2026-10-14' -> 'yesterday'; '2026-10-12' -> '3 days ago'; '2026-09-01' (44 days) -> 'on Sep 1, 2026'; null -> null
    - formatSqft(850) -> '850'; (1200) -> '1,200'; formatDistance(0.43) -> '0.4 mi'; formatPercent(6.4) -> '6%'
  </behavior>
