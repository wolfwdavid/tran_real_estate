# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: the Renter portal under `/renter/`: search, list and map results, listing detail, saved searches with "N new since last visit", shortlist board, fair-rent check, affordability calculator, and AI outreach. This phase **composes** the Phase 2-5 primitives and re-implements none of them.
> Design intelligence: UI/UX Pro Max (`src/ui-ux-pro-max/scripts/search.py`, run 2026-10-04: `--domain ux` for "filter chips search form", "data table mobile responsive", "kanban status board", "calculator slider input", "lazy load third party", "empty state search no results", "skeleton loading list", "sticky header scroll mobile tabs"; `--domain chart` for "sparkline trend" and "range comparison bullet"; `--domain product` for "real estate rental listing search"). **Adopted:** "No results" always offers a next step, never a bare "0 results"; loading feedback for anything over 300ms, using skeletons that reserve space; visible labels on every input and correct input types; tables on mobile scroll inside their own wrapper; lazy-load non-critical third-party code; a line chart for trends only with enough points, plus a data-table fallback; bullet-style range charts with every value shown as text; mobile-first breakpoints; and no horizontal page scroll. **Rejected:** the product row's "Glassmorphism + Trust Blue #0077B6 + Gold" (conflicts with the locked Phase 2 palette); location autocomplete (Tran has no geocoder host in CSP, and a lookup per keystroke would spend calls); drag-and-drop kanban (a native status `<select>` is keyboard- and screen-reader-safe; see `ShortlistBoard`); and the chart row's library picks (Chart.js/Recharts). A sparkline is a few lines of inline SVG. **No new hex values.**

**Sources legend:** `[CTX]` 06-CONTEXT.md (locked), `[P2]`…`[P5]` approved UI-SPECs of those phases, `[REQ]` REQUIREMENTS.md / ROADMAP.md (RENT-01..08), `[STACK]` CLAUDE.md, `[OSM]` OSM tile usage policy (operations.osmfoundation.org/policies/tiles, fetched 2026-10-04), `[CODE]` existing repo, `[SKILL]` UI/UX Pro Max, `[D]` researcher discretion (CONTEXT "Claude's Discretion" or a UI detail CONTEXT doesn't cover).

**Honesty rules for this phase (every string below follows them):**
1. A listing is never called "available". Tran knows only that RentCast **listed** it and when it was **last seen** listed. Recency is described as "listed within N days" or "last seen listed {relative}". The renter asks the listing contact about availability. Tran never claims it.
2. Rent figures from RentCast are "estimates" or "medians", never "appraisals", "values", or "fair market value". Comparisons are neutral ("above", "below", "about the same as"). Tran never says "overpriced", "good deal", or "bargain".
3. Every surface that renders fixture rows carries the "Sample data" chip on the same card `[P4]`.
4. Tran never contacts anyone. Phone, email, and message actions open the renter's own phone or email app.
5. The affordability calculator is "a general guideline, not financial advice", and its inputs are never saved.

## Typography

Reused: exactly **4 sizes** (14 / 16 / 24 / 40) and **2 weights** (400, 600) `[P2]`. Phase 6 adds no size and no weight.

| Role | Family | Size | Weight | Line Height | Phase 6 usage |
|------|--------|------|--------|-------------|---------------|
| Label | Inter | 14px | 600 (chips, badges, map pins, cluster counts, column counts, table headers in compact tables) / 400 (card meta lines, helper text, captions, "as of" lines, attribution, sample-size caveats) | 1.4 | Small meta and status |
| Body | Inter | 16px | 400 (paragraphs, card facts line, table cells, form inputs, notes) / 600 (field labels, legends, button labels, card address, `h3`s, result-count line, status-column titles) | 1.6 | Everything else |
| Heading | Fraunces | 24px | 600 | 1.25 | Section `h2`s, **rent figures** on listing cards and the detail header, affordability result range, dialog titles |
| Display | Fraunces | 40px | 600 | 1.1 | The single `h1` per route (listing detail: the street line of the address) |

Rules:
- **Every price, count, distance, percentage, and date uses `font-variant-numeric: tabular-nums lining-nums`** `[P4]`. Money is `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD', maximumFractionDigits: 0 })` ("$2,150"). Distances use one decimal ("0.4 mi"). Percentages are whole numbers ("6%").
- Rent on cards renders as Heading 24/600 "$2,150" followed by Body 16/400 `muted-foreground` " a month". The two sit in one text run, so the accessible text reads "$2,150 a month".
- Facts line uses a middle dot with spaces: "2 bd · 1 ba · 850 sq ft". Each abbreviation is wrapped in `<abbr title="bedrooms">` / `<abbr title="bathrooms">`, and the card's accessible summary (visually hidden, see `ListingCard`) spells them out.
- Addresses use `overflow-wrap: anywhere` so long unit strings never widen the page at 375px.
- `text-wrap: balance` on h1/h2 `[P2]`. No text below 14px. No Fraunces below 24px `[P3]`.

## Shape, Elevation, Motion

Phase 2 tokens `[P2]`. Listing cards, section cards, board cards: `--radius-lg`, `--shadow-card`. Pins, chips, badges, cluster bubbles: `--radius-full`. Inputs, selects, buttons, tables: `--radius-md`. Dialogs: `--radius-lg` + `--shadow-card-hover`.

- Listing cards lift like Phase 2 portal cards (`translateY(-2px)` + `--shadow-card-hover`, 200ms, `motion-safe:` only), because the whole card is a link `[P2]`. Board cards do not lift (they hold controls).
- **Skeletons** appear only when a gateway request takes longer than 300ms `[SKILL]`: `surface` blocks matching the card layout, `motion-safe:animate-pulse` (opacity only), static under reduced motion.
- **Map motion:** `fitBounds` and cluster-zoom use Leaflet's `animate: true` only under `prefers-reduced-motion: no-preference`. Otherwise every pan and zoom is instant (`animate: false`, `zoomAnimation: false`, `fadeAnimation: false`, `markerZoomAnimation: false`).
- List ↔ map highlight changes are instant (no transitions on pins).
- Scroll-into-view of a selected list card uses `behavior: 'smooth'` under `motion-safe` and `'instant'` otherwise. It never scrolls the page while the user is typing in a filter.
- Filter panel and notes editor open instantly (no height animation) `[P2]`.

### Map contract (`ListingMap`) `[CTX]` `[OSM]` `[D]`

**Tiles (live mode):** `L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', { maxZoom: 19, attribution })`. Rules from the OSM tile usage policy `[OSM]`:
- HTTPS host exactly `tile.openstreetmap.org`.
- **Attribution visible on the map, bottom-right, never hidden or collapsed:** "© OpenStreetMap contributors", linked to `https://www.openstreetmap.org/copyright`.
