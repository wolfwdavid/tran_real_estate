    - sniffLogo(bytes) → 'png' when the first 8 bytes are 89 50 4E 47 0D 0A 1A 0A; → 'svg' for ASCII text that, after an optional UTF-8 BOM (EF BB BF), whitespace, an optional `<?xml …?>`, any number of `<!-- … -->` comments and an optional `<!DOCTYPE svg …>`, starts with `<svg` (case-insensitive, followed by whitespace or `>`); → null for JPEG (FF D8 FF), GIF ('GIF89a'), '<html>…' text, '<svgx' and an empty array
    - checkLogoFile({ size, bytes }) → { ok: false, reason: 'too-large', size } when size > 524288 (checked BEFORE sniffing); { ok: false, reason: 'not-png-or-svg' } when sniffLogo is null; { ok: true, kind } otherwise
    - pngSize(bytes) reads width/height from the IHDR chunk (big-endian uint32 at offsets 16 and 20) → { width, height }; returns null if the IHDR tag at offset 12-15 is not 'IHDR'
    - svgIntrinsicSize(text) uses width/height attributes on the root <svg> when both are plain numbers or end in 'px'; else the viewBox's 3rd/4th numbers; else null. ('<svg width="200" height="100">' → 200×100; '<svg viewBox="0 0 640 160">' → 640×160; '<svg width="50%">' → null)
    - rasterTargetSize({ width: 3000, height: 750 }) → { width: 1024, height: 256 }; ({ width: 400, height: 100 }) → { width: 400, height: 100 } (never upscale); ({ width: 0, height: 10 }) → null
    - isOversizedRaster({ width: 4097, height: 10 }) === true
  </behavior>
