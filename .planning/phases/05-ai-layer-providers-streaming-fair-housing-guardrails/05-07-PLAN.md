Anthropic
- Stream: `POST https://api.anthropic.com/v1/messages`, headers exactly `{ 'content-type': 'application/json', 'x-api-key': key, 'anthropic-version': '2023-06-01', 'anthropic-dangerous-direct-browser-access': 'true' }`, body `{ model, max_tokens: maxTokens, system, messages: [{ role: 'user', content: user }], stream: true, ...extrasFor('anthropic', model) }`. Never send temperature/top_p/top_k.
- Events (switch on `JSON.parse(data).type`; ignore the SSE event name): `message_start` → usage `{inputTokens: message.usage.input_tokens}`; `content_block_delta` with `delta.type === 'text_delta'` → text `delta.text` (ignore `thinking_delta`, `signature_delta`, `input_json_delta`); `message_delta` → usage `{outputTokens: usage.output_tokens}` (cumulative, take last) and, when `delta.stop_reason` is set, finish (`end_turn`/`stop_sequence` → 'stop', `max_tokens` → 'length', `refusal` → 'refused'); `message_stop` → terminal; `error` → throw `LlmError('interrupted', {code: error.type})`; `ping`, `content_block_start`, `content_block_stop` and unknown types → ignore. Body ending without `message_stop` → throw `LlmError('interrupted', {code:'truncated'})`.
- Probe: keyCheck `GET https://api.anthropic.com/v1/models?limit=1000` with `x-api-key`, `anthropic-version`, `anthropic-dangerous-direct-browser-access` → `{status, body: await safeJson(res)}`; modelListed: `keyCheck.body.data[].id` includes model (undefined if shape unknown); canary: `POST https://api.anthropic.com/v1/messages` body `'{}'` with headers `content-type`, `anthropic-version`, `anthropic-dangerous-direct-browser-access` and NO `x-api-key` (expect 401, CORS-readable).

OpenAI
- Stream: `POST https://api.openai.com/v1/responses`, headers exactly `{ authorization: 'Bearer ' + key, 'content-type': 'application/json' }`, body `{ model, instructions: system, input: user, max_output_tokens: maxTokens, stream: true, store: false, ...extrasFor('openai', model) }`.
- Events by `type`: `response.output_text.delta` → text `delta`; `response.completed` → usage `{inputTokens: response.usage.input_tokens, outputTokens: response.usage.output_tokens, reasoningTokens: response.usage.output_tokens_details?.reasoning_tokens}` then finish 'stop' (terminal); `response.incomplete` → usage if present, finish 'length' when `response.incomplete_details.reason === 'max_output_tokens'`, 'refused' when `'content_filter'` (terminal); `response.refusal.delta` → finish 'refused' once (never yield refusal text); `error` → throw `LlmError('interrupted', {code})`; `response.failed` → throw `LlmError('interrupted', {code: response.error?.code})`; everything else (`response.created`, `response.in_progress`, `response.output_item.added`, `response.content_part.added`, `response.reasoning_summary_text.delta`, …) → ignore. Body ending without a terminal event → `LlmError('interrupted', {code:'truncated'})`.
- `output_tokens` already includes reasoning tokens (billed output), so do not add them again.
- Probe: keyCheck `GET https://api.openai.com/v1/models` with `authorization`; modelListed: `body.data[].id` includes model; canary: `POST https://api.openai.com/v1/responses` body `'{}'` with only `content-type` (expect 401, CORS-readable).

const BASE = 'https://api.anthropic.com';
const COMMON = { 'anthropic-version': '2023-06-01', 'anthropic-dangerous-direct-browser-access': 'true' } as const;
export const anthropicProbe: ProviderProbe = { id: 'anthropic', host: hostFor('anthropic'), keyCheck, modelListed, canary };
export function anthropicProvider(deps: AdapterDeps): LlmProvider {
  return { id: 'anthropic', async *stream(req, signal) {
    const key = await deps.getKey(); if (!key) throw new LlmError('locked');
    const res = await openStream({ probe: anthropicProbe, key, deps, url: `${BASE}/v1/messages`, init: { method: 'POST', signal,
      headers: { 'content-type': 'application/json', 'x-api-key': key, ...COMMON },
      body: JSON.stringify({ model: req.model, max_tokens: req.maxTokens, system: req.system,
        messages: [{ role: 'user', content: req.user }], stream: true, ...extrasFor('anthropic', req.model) }) } });
    let terminal = false;
    for await (const { data } of readSse(res, signal)) { /* switch per <context> protocol */ }
    if (!terminal) throw new LlmError('interrupted', { code: 'truncated' });
  } };
}
