# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Design intelligence: UI/UX Pro Max (`search.py --domain ux` for "streaming AI response loading stop button", "inline validation highlight error text", "confirmation dialog default action cancel", "reduced motion animation", "copy clipboard feedback success", and "live region screen reader dynamic content", run 2026-10-04). **Adopted:** stream text token by token instead of a long spinner (AI Interaction / Streaming), errors announced and never shown by a red border alone, confirm before risky actions, confirm every successful action, respect `prefers-reduced-motion`, animate at most one element per view (the streaming caret), and ease-out timing. **Rejected:** thumbs up/down and a "Regenerate"-style feedback loop as a panel exit (there is no backend to receive feedback, and the exits are locked to three), `role="alert"` for errors (Phase 3 locked a single polite live region), and toast confirmations (security- and compliance-relevant state must persist inline). No skill color or font output was used. Phase 2 and Phase 3 tokens, scale, and voice are reused exactly. **No new hex values.**

**Sources legend:** `[CTX]` 05-CONTEXT.md (locked), `[P2]` approved 02-UI-SPEC.md, `[P3]` approved 03-UI-SPEC.md, `[P4]` 04-CONTEXT.md, `[REQ]` REQUIREMENTS.md / ROADMAP.md (AI-01..04), `[STACK]` CLAUDE.md, `[SKILL]` UI/UX Pro Max, `[D]` researcher discretion (CONTEXT "Claude's Discretion" or a UI detail CONTEXT does not address).

## Typography

Reused: exactly **4 sizes** (14 / 16 / 24 / 40) and **2 weights** (400, 600) `[P2]`. Phase 5 introduces no size and no weight.

| Role | Family | Size | Weight | Line Height | Phase 5 usage |
|------|--------|------|--------|-------------|---------------|
| Label | Inter | 14px | 600 (chips, status badges, popover severity line) / 400 (usage/cost line, helper text, "Last updated" style meta, history timestamps, exit helper line) | 1.4 | Small meta and status |
| Body | Inter | 16px | 400 (draft text, prompt preview, explanations, descriptions) / 600 (button labels, panel title when `h3`, field labels, findings summary title, category name in popover, radio option titles) | 1.6 | Everything else, including the streamed draft |
| Heading | Fraunces | 24px | 600 | 1.25 | Settings section `h2` "AI drafting", dialog titles, `GenerationPanel` title when rendered as `h2` in a portal |
| Display | Fraunces | 40px | 600 | 1.1 | Not used by Phase 5 components (page `h1`s belong to host pages) |

Rules:
- The draft text is **Body 16/400 at line-height 1.6**, `white-space: pre-wrap`, `overflow-wrap: anywhere`. Never Fraunces, never smaller than 16px (it is the content the user will send).
- Plain text output only. If a feature prompt returns markdown, it renders through DOMPurify-sanitized markdown limited to paragraphs, line breaks, lists, and bold. No headings inside the draft, so the draft never adds Fraunces or new sizes. Never `{@html}` of raw model output `[CTX]`.
- Token counts, cost figures and timestamps use `tabular-nums`.
- Model IDs (e.g. `claude-sonnet-5`) render in `<code>` styled as Body 16/400 Inter (Label 14/600 inside chips), no tint, `overflow-wrap: anywhere` `[P3]`.
- The panel title's heading level is a prop (`headingLevel: 2 | 3`, default 3). Visual role follows level: `h3` = Body 16/600, `h2` = Heading 24/600. The findings summary title is one level below the panel title.

## Shape, Elevation, Motion

Phase 2 tokens `[P2]`: `--radius-md` 8px (buttons, output box, textarea, prompt preview block, inputs), `--radius-lg` 16px (panel, popover, dialogs, alerts, history rows), `--radius-full` (chips, badges). `--shadow-card` on the panel; `--shadow-card-hover` on the popover and dialogs. `--ease-out`, `--duration-fast` 150ms, `--duration-base` 200ms.

- **Streaming render throttle** `[CTX]`: token deltas accumulate in a buffer and flush to the DOM at most every **50ms** (one `requestAnimationFrame`-aligned flush per 50ms window). The output box grows downward; it reserves 160px from the start. The page never auto-scrolls during streaming (it would steal the reader's position). Text appearing is content, not decoration, so it is not suppressed under reduced motion.
- **Streaming caret**: a `<span aria-hidden="true">` after the last character, 2px × 1em, `foreground`. Blink: `opacity` 1 → 0 with `steps(1)` over 1000ms, wrapped in `motion-safe:`. Under `prefers-reduced-motion: reduce` the caret is **static** (always visible, no blink). Removed when the stream ends, stops, or errors. This is the only animated element in the panel `[SKILL excessive-motion]`.
- In-flight indicators (Testing…, Connecting…) use Lucide `LoaderCircle` 16px `animate-spin` under `motion-safe:` only; static under reduced motion `[P3]`.
- Popover open/close: `opacity` 0→1 over 150ms under `motion-safe:`; instant under reduced motion. No scale or slide.
- Dialogs follow Phase 3 `[P3]`.
- Applying an alternative swaps text instantly (no highlight flash animation).
- "What will be sent" disclosure opens instantly (no height animation).

### Focus management

| Event | Focus moves to |
|-------|----------------|
| Generate draft pressed | Stays on the same button, which becomes **Stop** (same element, label and variant swap). Focus is never lost. |
| Stop pressed / stream ends | Stays on the same button (now **Generate again**). The result is announced. |
| Stream ends with findings | Focus stays put; the announcement states the count. The user reaches the findings list next in tab order (output → findings → exits). |
| Inline trigger activated | Popover opens; focus moves to the popover's **Use alternative** button. `Escape` closes and returns focus to the trigger. |
| Use alternative applied | Focus moves to the **next unresolved finding trigger** in reading order; if none remain, to the findings summary title (`tabindex="-1"`). |
| "Show in draft" (findings list) | Leaves edit mode if active, scrolls the mark into view (`block: 'center'`, instant under reduced motion), focuses its trigger. |
| Edit draft | Focus moves into the textarea, caret at the end. |
| Done editing | Focus returns to the **Edit draft** button. |
| A gated exit is activated (`aria-disabled`) | No action; focus moves to the findings summary title and the gating reason is announced. |
| Gemini dialog opens | **Don't send to Gemini** (initial focus) `[CTX Cancel is default]`. Close returns focus to **Generate draft**. |
| Error alert appears | Focus stays on the Generate/Stop button; the alert is announced. The alert's action link is next in tab order after the output. |
| Draft history "Open" | Focus moves to the panel's output box (`tabindex="-1"`, `aria-label="Draft"`). |
| Delete draft confirmed | Focus moves to the Draft history title (`tabindex="-1"`). |

### `GenerationPanel` anatomy

Container: `<section aria-labelledby="{id}-title">` on `card`, 1px `border`, `--radius-lg`, `--shadow-card`, padding 24px (16px below 640px), regions separated by 24px. Max width 640px. `aria-busy="true"` while streaming.

Each block: `surface` fill, `--radius-md`, padding 16px, Body 16/400, `white-space: pre-wrap`, max-height 320px with `overflow-y: auto`, `tabindex="0"`, `aria-label` = its label.
4. **Run control**: one `button` element whose label and variant follow state: **Generate draft** (primary, Lucide `PenLine` 16px) → while streaming **Stop** (outline, Lucide `Square` 16px) → after a draft exists **Generate again** (outline, Lucide `RotateCcw` 16px) with helper (Label 14/400 muted) "Your current draft stays in Draft history." 48px tall; full width below 640px. ## Security & Privacy UI Rules `[CTX]`

- Key values never appear in the panel, the "What will be sent" preview, error messages, announcements, history rows, or `title`/`aria-*` attributes `[P3]`.
- The "What will be sent" preview shows the exact post-redaction payload text; redaction originals appear only in the local "Replaced before sending" list and are never stored in the artifact (the artifact stores `inputHash`, not raw inputs).

- `mailto:` links are built only from the draft text and the feature's `to`/`subject` props; no tracking parameters.
- Model output renders as text (or sanitized limited markdown); the existing lint rule bans `{@html}` on model output.
- CSP unchanged: all four provider hosts are already in `connect-src` `[CTX]`.
