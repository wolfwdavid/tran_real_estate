Wire protocol (RESEARCH Pattern 1, verified 2026-10-04):

Gemini
- Stream: `POST https://generativelanguage.googleapis.com/v1beta/models/${encodeURIComponent(model)}:streamGenerateContent?alt=sse`, headers exactly `{ 'content-type': 'application/json', 'x-goog-api-key': key }`, body `{ systemInstruction: { parts: [{ text: system }] }, contents: [{ role: 'user', parts: [{ text: user }] }], generationConfig: { maxOutputTokens: maxTokens, ...extrasFor('gemini', model) } }` (for 'gemini-3.8-flash' this adds `thinkingConfig: { thinkingLevel: 'low' }`).
- Consent: if `req.containsClientData && req.clientDataAck !== true` → `throw new LlmError('consent-required')` BEFORE `getKey()` and before any fetch.
- Non-OK responses are handled by `openStream` → `classifyHttp` over `safeJson` (the 400 body is JSON even though `content-type` is `text/event-stream`).
- Each `data:` is one GenerateContentResponse JSON: top-level `error` → `LlmError('interrupted', {code: error.status})`; `promptFeedback.blockReason` (no candidates) → finish 'refused' (terminal); `candidates[0].content.parts[]` → yield text for each part with `part.thought !== true` and a string `text`; `candidates[0].finishReason`: 'STOP' → 'stop', 'MAX_TOKENS' → 'length', any of 'SAFETY','PROHIBITED_CONTENT','BLOCKLIST','SPII','RECITATION' → 'refused', other values → 'stop' (terminal when present); `usageMetadata` (keep last): `{ inputTokens: promptTokenCount, outputTokens: (candidatesTokenCount ?? 0) + (thoughtsTokenCount ?? 0), reasoningTokens: thoughtsTokenCount }` yielded once at the end before finish.
- Probe: keyCheck `GET https://generativelanguage.googleapis.com/v1beta/models?pageSize=1000` with `x-goog-api-key`; modelListed: look for `models[].name === 'models/' + model`, following `nextPageToken` via `&pageToken=${encodeURIComponent(token)}` for at most 5 pages (key in header every time); canary: `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:streamGenerateContent?alt=sse` body `'{}'` with only `content-type` (expect 403, CORS-readable).

OpenRouter
- Stream: `POST https://openrouter.ai/api/v1/chat/completions`, headers exactly `{ authorization: 'Bearer ' + key, 'content-type': 'application/json', 'x-openrouter-title': 'Tran Real Estate Tools' }`, body `{ model, messages: [{ role: 'system', content: system }, { role: 'user', content: user }], max_tokens: maxTokens, stream: true, provider: { data_collection: 'deny' }, ...extrasFor('openrouter', model) }`.
- Stream: comments (': OPENROUTER PROCESSING') are dropped by the parser; `data: [DONE]` → terminal; JSON with top-level `error` → `LlmError('interrupted', {code: String(error.code)})` (may be the only chunk on a 200); `choices[0].delta.content` (string, non-empty) → text (ignore `delta.reasoning`); `choices[0].finish_reason`: 'stop' → 'stop', 'length' → 'length', 'content_filter' → 'refused', 'error' → `LlmError('interrupted', {code:'finish-error'})`; chunk `usage` → `{ inputTokens: prompt_tokens, outputTokens: completion_tokens, costUsd: cost }` (cost is provider-reported USD).
- Probe: keyCheck `GET https://openrouter.ai/api/v1/key` with `authorization` (the public `/api/v1/models` returns 200 without a key and must NOT be used to validate keys); modelListed: `GET https://openrouter.ai/api/v1/models` with NO authorization header, `data[].id` includes model; canary: `POST https://openrouter.ai/api/v1/chat/completions` body `'{}'` with only `content-type` (expect 401).
