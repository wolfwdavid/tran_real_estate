| workflow -> GitHub API | read-only token leaves the job in a header |
| superseded decision -> run result | a wrong answer could turn a real red green |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-08 | Tampering | version.json value in the compare URL | mitigate | served and expected SHAs must match 40-hex before any URL is built; repository validated by regex; unit-tested rejection without calling get |
| T-18-09 | Repudiation | superseded path masking a real failure | mitigate | only an explicit `ahead` for a different 40-hex SHA counts; behind, diverged, null, missing token, API error all keep exit 1, 2 or 3; superseded runs never count toward the three-run proof |
| T-18-10 | Information disclosure | token in logs or URL | mitigate | token only in an Authorization header, never logged; unit test asserts the token is absent from the URL; permissions stay contents: read; no secrets. reference |
| T-18-11 | Elevation of privilege | workflow gains permissions or actions | mitigate | env line only; gate pins exactly four pinned uses, no write, no gh CLI, no secrets. |
| T-18-12 | Denial of service | compare API unreachable or rate limited | accept | fail closed: the smoke behaves exactly as today (red) and the lookup is asked once per distinct served SHA |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | no package is installed in this phase |
