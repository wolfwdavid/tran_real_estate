```js
const words = (s) => s.trim().split(/\s+/).join('\\s+');
export const BANNED = [
	['appraisal', /\bappraisals?\b/i],
	['appraise', /\bapprais(?:e|es|ed|ing|er|ers)\b/i],
	['guarantee', /\bguarantee(?:s|d)?\b/i],
	['guaranty', /\bguarant(?:y|ies)\b/i],
	['best investment', new RegExp(`\\b${words('best investment')}s?\\b`, 'i')],
	['we represent', new RegExp(`\\b${words('we represent')}\\b`, 'i')],
	['brokerage services', new RegExp(`\\b${words('brokerage services')}\\b`, 'i')],
	['risk-free', /\brisk[-\s]?free\b/i],
	['will appreciate', new RegExp(`\\b${words('will appreciate')}\\b`, 'i')],
	['passive income', new RegExp(`\\b${words('passive income')}\\b`, 'i')],
	['testimonial', /\btestimonials?\b/i],
	['rated 5', /\brated\s+5\b|\b(?:5|five)[-\s]star\b/i],
	['star glyph', /[★☆]|&#9733;|&#x2605;|&starf;|&#9734;|&star;/i],
	['trusted by', new RegExp(`\\b${words('trusted by')}\\b`, 'i')],
	['thousands of', new RegExp(`\\b${words('thousands of')}\\b`, 'i')]
];
export const SCOPE = ['apps/web/src/routes', 'apps/web/src/lib/components', 'apps/web/src/lib/content'];
export const SCANNED_EXT = /\.(svelte|ts|js|md)$/i;
export const EXCLUDED = /\.(test|spec)\.[tj]s$/i;
```
`findBanned(file, text)`: for each [label, re], clone as `new RegExp(re.source, re.flags.includes('g') ? re.flags : re.flags + 'g')`, iterate `text.matchAll`, line = count of `\n` before `m.index` + 1, push `${file}:${line}: banned term "${label}" (matched "${m[0].replace(/\s+/g, ' ')}")`. Matching runs over the WHOLE text (not per line) so Prettier-wrapped phrases are caught.

`scripts/banned-terms.mjs` CLI:
- `export function collectFiles(root)`: for each SCOPE dir, `join(root, dir)`; skip if `!existsSync`; `readdirSync(abs, { recursive: true, withFileTypes: false })` (Node 24), keep entries whose `statSync` is a file, matching SCANNED_EXT and not EXCLUDED; return repo-relative POSIX paths (`relative(root, f).split(sep).join('/')`). Uses fs, never `git ls-files`, so new unstaged pages are scanned.
- main (guarded by the pathToFileURL idiom): parse `--root <dir>` (default `process.cwd()`); files = collectFiles(root); if `files.length === 0` print `Banned-terms check scanned 0 files; scope is misconfigured` to stderr and exit 1; collect hits from `findBanned(rel, readFileSync(abs,'utf8'))`; on hits print them to stderr and exit 1; else print `Banned-terms check passed (${files.length} files)`.
Do not add any allowlist (UI-SPEC: "Do not add an allowlist"). Run tests GREEN, commit `feat(02-02): banned-terms rules and CLI`.
