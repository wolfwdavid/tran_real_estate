# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Design intelligence: UI/UX Pro Max (`search.py --design-system "real estate SaaS tools editorial warm serif"` plus domain searches for color, typography, style, landing, run 2026-10-04). The skill's generic output (teal palette, Cinzel + Josefin Sans, Google Fonts CDN) conflicts with locked CONTEXT.md decisions and was **rejected**. Adopted from the skill: the "Nature Distilled" style (terracotta, sand, cream, olive, soft shadows, ease-out motion), the Calistoga + Inter note (warm display serif with Inter for UI, 16px body), the "How it works" landing section, the trust-signal emphasis, and every Quick Reference rule in §1-§9 that applies to a static marketing site.

**Sources legend:** `[CTX]` 02-CONTEXT.md (locked), `[REQ]` REQUIREMENTS.md / ROADMAP.md, `[CODE]` existing repo code, `[SKILL]` UI/UX Pro Max, `[D]` researcher discretion (CONTEXT "Claude's Discretion").

## Spacing Scale

Declared values (all multiples of 4). Exposed as Tailwind's default `--spacing: 4px` multiplier. Only the steps below are used.

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `1` | Icon-to-label gap inside buttons and links, underline offset area |
| sm | 8px | `2` | Gap between stacked label and value, gap between CTA buttons on mobile, gap between touch targets |
| md | 16px | `4` | Default element spacing, nav link horizontal padding, card inner stack gap, mobile menu row padding |
| lg | 24px | `6` | Card padding, page gutter below 768px, gap between grid cards |
| xl | 32px | `8` | Page gutter at 768px and up, gap between hero copy and portal cards, footer column gap |
| 2xl | 48px | `12` | Section vertical padding below 768px, hero top padding on mobile |
| 3xl | 64px | `16` | Section vertical padding at 768px and up, header height (64px) |
| 4xl | 96px | `24` | Hero top and bottom padding at 1024px and up only |

Layout constants:

| Constant | Value | Usage |
|----------|-------|-------|
| `--container-page` | 1120px (70rem) | Max width of header, footer and section content. Centered, with gutters from the table above. |
| `--container-prose` | 640px (40rem, about 68 characters of 16px Inter) | Max width of legal page body, audience-page lead, hero subhead `[SKILL line-length 65-75]` |
| Breakpoints | 640px (`sm`), 768px (`md`), 1024px (`lg`) | 640 = nav collapse threshold `[CTX]`. 768 = grids go multi-column. 1024 = hero spacing grows. Tailwind defaults, no custom breakpoints. |

Exceptions:
- Interactive minimum hit area is **44x44px** for every link and button, including footer links and inline nav links. Footer links in a list get `min-height: 44px` with `display: inline-flex; align-items: center` `[SKILL touch-target-size]`. Exception: inline links inside running paragraphs, which WCAG 2.5.8 exempts.
- Skip link focus position: `top: 8px; left: 8px`.
- Focus outline offset: 2px. This is a ring geometry value, not a spacing step.

## Typography

Exactly **4 sizes** (14 / 16 / 24 / 40) and **2 weights** (400 regular, 600 semibold) across both families.

| Role | Family | Size | Weight | Line Height | Letter spacing | Used for |
|------|--------|------|--------|-------------|----------------|----------|
| Label | Inter | 14px (0.875rem) | 600 | 1.4 | 0.06em when uppercase eyebrow, otherwise 0 | Eyebrows ("For renters", "How it works"), "Last updated" lines, footer legal links and disclaimer, button labels are NOT this (see Body) |
| Body | Inter | 16px (1rem) | 400 (600 for button labels, nav current item, h3) | 1.6 | 0 | All paragraphs, nav links, buttons, list items, card body, legal text, h3 (Inter 600) |
| Heading | Fraunces | 24px (1.5rem) | 600 | 1.25 | -0.005em | h2 section headings, portal-card titles, footer wordmark, header wordmark at 640px and up |
| Display | Fraunces | 40px (2.5rem) | 600 | 1.1 | -0.015em | The single h1 on each page (hero headline, audience-page headline, legal page title, portal placeholder title, error title) |

Rules:
- Semantic level and visual role are separate. h1 always uses Display. h2 uses Heading. h3 uses Body at weight 600 (Inter), except **portal-card titles on the landing page**, which are `h3` elements styled as Heading so cards read as editorial objects.
- Header wordmark: Fraunces 600, 16px below 640px (Body size) and 24px at 640px and up (Heading size). This keeps "Tran Real Estate Tools" plus the 44px menu button inside 327px of usable width at 375px.
- Fraunces is used only at 24px and 40px plus the mobile wordmark. Never set body copy in Fraunces.
- `text-wrap: balance` on h1 and h2. `text-wrap: pretty` on paragraphs.
- `font-optical-sizing: auto` (Fraunces has an opsz axis).
- Font stacks (also `[CODE]` tokens): `--font-display: 'Fraunces Variable', Georgia, 'Times New Roman', serif;` and `--font-sans: 'Inter Variable', ui-sans-serif, system-ui, -apple-system, 'Segoe UI', sans-serif;`
- `font-display: swap` (the Fontsource default) `[SKILL font-loading]`. Import only the default `wght`-axis entry of each package, not the `full` axes builds.
- Numerals: `font-variant-numeric: tabular-nums` on any figure in How-it-works step numbers `[SKILL number-tabular]`.
- No body text below 14px anywhere. 14px is limited to Label-role text.
- `html { -webkit-text-size-adjust: 100%; text-size-adjust: 100%; }`. Never disable zoom `[SKILL viewport-meta]`.

**Accent (terracotta `#A4452A`) is reserved for exactly these elements:**
1. Primary CTA button fill ("Open renter portal" etc., and the hero "Choose your portal" button)
2. Inline links inside running text (legal pages, disclaimers, lead paragraphs), always underlined
3. Focus outline (`--color-ring`) on every focusable element

5. Step numerals "1 / 2 / 3" in How it works

Terracotta is **not** used for headings, nav links in their resting state, card borders, icons, or backgrounds of large areas. Decorative terracotta (`#C8714E`) appears only inside `aria-hidden` illustrations.

## Shape, Elevation, Motion

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 4px | Skip link, inline focus outline corners |
| `--radius-md` | 8px | Buttons, mobile menu button, menu panel rows |
| `--radius-lg` | 16px | Cards, trust strip items, "What it is not" callout |
| `--radius-full` | 9999px | Property-mark disc, step-numeral disc |
| `--shadow-card` | `0 1px 2px rgb(43 29 22 / 0.06), 0 8px 24px -12px rgb(43 29 22 / 0.18)` | Portal cards and feature cards at rest |
| `--shadow-card-hover` | `0 2px 4px rgb(43 29 22 / 0.08), 0 16px 32px -16px rgb(43 29 22 / 0.24)` | Portal card hover and focus-within |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | All transitions `[SKILL easing]` |
| `--duration-fast` | 150ms | Color, background, and underline transitions |
| `--duration-base` | 200ms | Card lift and shadow |

Motion rules `[SKILL §7]`:
- Animate only `color`, `background-color`, `border-color`, `box-shadow`, `opacity`, `transform` `[SKILL transform-performance]`.
- Portal card hover / `:focus-within`: `translateY(-2px)` plus `--shadow-card-hover` over 200ms.
- Buttons: background color over 150ms, `:active` → `translateY(1px)`.
- Mobile menu panel opens and closes **instantly**, with no height animation (no CLS, nothing to reduce).
- `@media (prefers-reduced-motion: reduce)`: every `transform` is removed and transition durations go to `0ms`. Color changes still apply.
- No scroll-triggered reveals, parallax, or auto-playing motion anywhere in Phase 2.

## Imagery & Texture `[CTX]`

- **No photos.** No raster images at all in Phase 2. No external assets.
- **Hero texture (CSS):** two layered `radial-gradient`s on the hero section, declared in the stylesheet (not inline `style`, not `data:` URIs):
  `radial-gradient(60% 55% at 88% 8%, #F6E3D8 0%, transparent 70%), radial-gradient(45% 40% at 4% 92%, #E4EADF 0%, transparent 70%)` over `#FBF7F0`. Text contrast is computed against the lightest and darkest stops, so the matrix above holds everywhere (the tints are the `accent-surface` and `secondary-surface` columns).
- **Contour-line motif (inline SVG):** one `aria-hidden="true" focusable="false"` SVG of 6-8 concentric, irregular topographic contour paths, stroke `#E2D5C3`, 1px, no fill. It is positioned absolutely at the hero's top-right, `pointer-events: none`. It is shown at 768px and up only. The hero uses `overflow: clip` so it can never cause horizontal scroll.
- **Property-type marks (inline SVG components, `$lib/components/brand/marks/`):** 64x64 viewBox, rendered at 64px. Strokes `#2B1D16` at 1.5px with round joins. Fills from `deco-terracotta`, `deco-sage` and `surface`. All `aria-hidden="true"`, because the card heading carries the meaning.
  - `RenterMark`: a three-storey apartment block with a 3x3 window grid and a door.
  - `InvestorMark`: a two-unit duplex with a small ruled ledger card leaning against it. No upward arrows or charts, because that would imply returns.
  - `AgentMark`: a single-family house with a speech bubble at the upper right.
  - Each mark sits centered in a 96px `--radius-full` disc of `--color-accent-surface`.
- CSP check: inline `<svg>` elements and stylesheet gradients are allowed by `default-src 'self'` / `style-src 'self'`. **Forbidden:** `data:` URIs anywhere (fonts, backgrounds, `<img>`), because `img-src` and `font-src` fall back to `'self'`. Set `build.assetsInlineLimit: 0` in the Kit Vite config so Vite never inlines a small woff2 or SVG as `data:`. The existing CSP E2E and oracle will catch a regression.

## CSP & Performance Constraints `[CTX locked]`

- No third-party requests of any kind: no Google Fonts, no CDN icons, no external images. Lucide renders inline SVG from the bundle.
- Fonts arrive through `import '@fontsource-variable/fraunces'; import '@fontsource-variable/inter';` in the root layout, so Vite emits hashed `.woff2` files under `_app/`. That is same-origin and allowed by `default-src 'self'`. Set `assetsInlineLimit: 0` so no `data:` font URIs appear.
- No inline `<style>` or `<script>` in `app.html`. Component `<style>` blocks compile into external CSS (allowed by `style-src 'self'`). Inline `style=""` attributes are allowed but should not be needed. Prefer classes.
- Marketing routes import no Dexie, LLM adapters, pdfmake or LayerChart `[CLAUDE.md stack pattern]`.
- No `<link rel="preload">` for fonts in Phase 2. Fontsource's `swap` is enough, and preloading hashed URLs needs a head hook that is not worth the complexity here.
