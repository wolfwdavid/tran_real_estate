<objective>
Cover the remaining exits that share the same stale-gate pattern (found while investigating the 09-VERIFICATION.md gap). The Snapshot Save button and the investor memo Print link sit outside the panel and gate on the panel's bindables (`canExit`, `findings`). Both already re-run the checks for Must-fix phrases, but not for Review phrases: a Review phrase typed after the agent acknowledged the earlier ones is only noticed 300 ms later, so Save or Print inside that window goes through without the acknowledgement. Fix: flush the panel's pending recheck (09-24's `GenerationPanel.flushChecks()`) and `flushSync()` before reading the gate.
