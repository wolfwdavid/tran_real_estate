<objective>
Cover the remaining exits that share the same stale-gate pattern (found while investigating the 09-VERIFICATION.md gap). The Snapshot Save button and the investor memo Print link sit outside the panel and gate on the panel's bindables (`canExit`, `findings`). Both already re-run the checks for Must-fix phrases, but not for Review phrases: a Review phrase typed after the agent acknowledged the earlier ones is only noticed 300 ms later, so Save or Print inside that window goes through without the acknowledgement. Fix: flush the panel's pending recheck (09-24's `GenerationPanel.flushChecks()`) and `flushSync()` before reading the gate.

The memo Print link also keeps a live href during a pending recheck, and a middle-click / new-tab open follows it without running onPrint, so MemoPage additionally binds 09-24's `checkPending` and withholds the href while it is true (same rule as the panel's email link).

Purpose: Phase 9 guarantee 2 for STU-04 (snapshot Save). The memo Print fix applies the same guarantee to the Phase 7 memo print exit (requirement INV-06, already complete in Phase 7; it is not re-claimed in this plan's frontmatter because the work is driven by the Phase 9 gap and uses the identical pattern).
Output: two small host fixes (Save flush; Print settle + withheld href), E2E regression steps, validation rows.
