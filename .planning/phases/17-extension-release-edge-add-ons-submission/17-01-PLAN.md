<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tag name / branch ref -> release script | `RELEASE_TAG` and `GITHUB_REF_NAME` are attacker-influenced for repo writers; read as data from env, never interpolated into shell |
| built zip -> store | whatever is inside the zip ships to users and the store |
| live site -> probe | an HTTP body from the public origin decides pass/fail |
| CHANGELOG text -> release notes | file content becomes public release text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | zip contents | mitigate | default-deny `ZIP_ENTRY_ALLOWLIST` in `checkZip`; mutant tests for .map, .ts, .env, .pem, dotfiles, nested and `..` paths; real zip drift test |
| T-17-02 | Information disclosure | stray secret or sourcemap in the zip | mitigate | same allowlist rejects `.env*`, `.map`, `.ts`; oracle keeps scanning bundle text for URLs and network tokens |
| T-17-03 | Spoofing / Tampering | release from a non-main commit | mitigate | `checkAncestor` fails closed on a non-ancestor and on an unresolvable ref; temp-repo tests for both |
| T-17-04 | Tampering | mis-versioned store submission | mitigate | `checkVersions` compares tag, package, built manifest and zip name; mismatch tests per pair |
| T-17-05 | Tampering (script injection) | tag name in shell | mitigate | scripts read `RELEASE_TAG` from env, git is spawned with an argv array and no shell, tag must match `^ext-v\d+\.\d+\.\d+$` |
| T-17-06 | Denial of service | transient Pages failure fails a release | accept | one attempt, 15 s abort; releases are rare and the owner re-runs; a drift to 404 should fail loudly |
| T-17-07 | Information disclosure | secret-looking text in docs | mitigate | no NAME_KEY=value assignments; test greps notes for the shape |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | no package is installed in this plan (Node builtins only); nothing to audit |
</threat_model>
